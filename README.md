# Fishing Minecraft — Câu Cá Vạn Cân

A Minecraft Bedrock add-on inspired by the giant-fish fishing challenge shown in KhanhsKG 3.0's video:
https://www.youtube.com/watch?v=HQRo09NfrHc

## Status
Initial project bootstrap. The add-on source, textures, and importable .mcaddon are being added.

## Target
Minecraft Bedrock Edition 1.26.52 (26.52) and newer stable Bedrock releases.

## Planned gameplay
- Cast a vanilla fishing rod near water to call the Titan Dragon Fish.
- Fight a 100,000,000 HP aquatic boss with a boss HUD.
- Re-cast/reel to deal fishing damage and receive a catch reward.
- Custom blocky fish model and texture; no external downloads required.

This is an original fan-made implementation. It is not affiliated with or endorsed by KhanhsKG 3.0 or Mojang.
