# Fishing Minecraft — Câu Cá Vạn Cân

Fan-made Minecraft Bedrock add-on inspired by the giant-fish challenge in KhanhsKG 3.0's video:
https://www.youtube.com/watch?v=HQRo09NfrHc

## Included in v1.0
- Custom blocky **TITAN DRAGON FISH** with orange-red body and golden fins/spines.
- 100,000,000 HP and a native Minecraft boss HUD.
- Tail and fin swim animation.
- Use a normal Minecraft fishing rod beside a lake/ocean to summon the fish.
- Use/reel the fishing rod again to deal **2,471,281 damage** per pull.
- Defeating it drops 3–7 Dragon Scales.
- `/function summon_titan` for a quick test spawn.

## Install
1. Open `FishingMC.mcaddon` with Minecraft Bedrock.
2. In your world settings, activate both **Câu Cá Vạn Cân - Behavior** and **Câu Cá Vạn Cân - Resources**.
3. Join the world, stand beside a large body of water, look toward the water and use a fishing rod.
4. When the boss appears, use the fishing rod repeatedly to reel it in.
5. To test without water, enable cheats and run `/function summon_titan`.

## Compatibility
Built for Bedrock 1.26.50+ with the stable `@minecraft/server` 2.10.0 module. The game runtime itself is not available in this build environment, so final in-game validation is still needed.
